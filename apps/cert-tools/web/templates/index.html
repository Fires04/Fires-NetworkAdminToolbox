About these two tools

Decrypt private key turns a password-protected RSA key -- e.g. the key a Mikrotik router exports for an OpenVPN client config -- into a plain PEM you can paste straight into a config file, with no further prompts for a passphrase at connect time.

Merge key + cert → .pfx bundles a private key together with its certificate (and, optionally, the intermediate/CA chain) into one password-protected PKCS#12 (.pfx) file -- the single-file format Windows Certificate Manager / IIS's "Complete Certificate Request" / "Import" wants, instead of three separate PEM files.

Nothing uploaded here is written to disk outside a short-lived temp directory for the duration of the request, and nothing is logged or retained afterward.
